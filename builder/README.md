# Kursassistent-byggeren

A Sikt KI-assistent that helps NHH teachers build a course assistant. It reads
the course page, interviews the teacher one question at a time, drafts the
instructions and advises on the other fields in the Sikt builder. Open it at
<https://ki.sikt.no/B53K>.

| File | What it is |
|:--|:--|
| [`instructions.md`](instructions.md) | The text in its Instructions field |
| [`sikt-settings.md`](sikt-settings.md) | One of its knowledge files: what each field in the Sikt builder does, what worked for the case study, and how to test |
| [`example-draft-bed3.md`](example-draft-bed3.md) | The draft it wrote for BED3 on 24 September 2026, with the answers taken from BED3-Buddy's instructions |

Its other knowledge files are the three files in [`../examples/`](../examples/).
