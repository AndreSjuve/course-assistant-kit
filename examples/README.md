# Handout: build your own course assistant

The three files a course responsible needs to start, from the seminar
[Building an AI assistant for your course](../slides.html) (NHH
seminar, 2026). The slides explain the reasoning; these files are the
starting point so nobody begins from a blank box.

| File | What it is | How to use it |
|:--|:--|:--|
| [`instructions.md`](instructions.md) | The instruction text of the case-study course assistant, with a header on what the tutor stance and the refusal rules are doing | Copy, replace the course facts, keep the stance and the refusals |
| [`knowledge-files.md`](knowledge-files.md) | An inventory of the kinds of files worth uploading, one rule per kind, with the ones the case study used marked | Walk through it before you gather anything from your course |
| [`note-to-students.md`](note-to-students.md) | The note that tells students what the assistant is, what it will not do, that it can be wrong, and that it is the course's sanctioned AI | Adapt and post it on Canvas next to the link |

No actual course files are included; the inventory describes kinds of files
only. The platform these were written for is Sikt KI-assistent, but nothing in
them depends on it: the same three files work in any tool that takes
instructions and uploaded documents.
